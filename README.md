## Installation & Running

1. Clone the repo

```bash
git clone https://github.com/verpenunes/social-media-client.git
```

2. Install the dependencies

```bash
npm install
```

3. Run Build/SASS

```bas
npm run start
```

```bas
npm run build
```

## Testing

Jest Test

```bash
npm run test-unit
```

Cypress Test

```bash
npm run test-e2e
```

Both Cypress & Jest Test

```bash
npm run test
```
