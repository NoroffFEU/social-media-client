# Workflow CA

## Description

This project improves the quality of a social media client application by implementing Cypress for end-to-end testing and modern development workflows.

Features include:

- Login form connected to a JWT API
- Logout functionality
- Cypress E2E tests for login and logout
- Configured with ESLint, Prettier, and Husky for code quality

## Getting Started

### Installation

#### 1. Clone the repository:

```bash
git clone https://github.com/caagedal/social-media-client.git

```
#### 2. Install the dependencies

```bash
npm i
```

or 

```bash
npm install
```

### Running

```bash
npm run start
```

In another terminal window:

```bash
npm run dev
```


### Run tests

#### Run unit tests:

```bash
npm run test-unit
```

#### Run E2E tests:

```bash
npm irun test-e2e
```
